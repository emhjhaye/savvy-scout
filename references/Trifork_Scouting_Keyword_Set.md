# Trifork UK Scouting — Combined Keyword Set

Sector-first design. Generic terms (originally Kanvesh's) are qualifiers to pair with a sector term, not standalone searches — running them alone floods Phase 1 with out-of-scope notices, as seen today with Digital Experience Platform and Legacy Infrastructure Support (both used generic "platform"/"digital" language with no sector coupling).

---

## Fintech

**Primary terms** (run standalone — sector is inherent):
- real-time payments
- payments platform
- digital wallet
- open banking
- clearing and settlement
- banking API
- systems assurance

**Qualified generic terms** (pair with fintech / bank / payments):
- data platform + fintech
- digital identity + banking
- secure communications + bank
- AI services + payments
- API integration + banking
- cloud platform + fintech

**Exclusions** (disguised-hardware trap):
- ATM supply
- card printing

---

## Generic terms — use only as qualifiers, never standalone

These pull volume from every sector when run alone, most of which Phase 1 has to eliminate on sight:

data · digital · secure · security · identity · AI · artificial intelligence · software · software development · application · development · agile · agile delivery · cloud platform · secure messaging · secure communications · API integration · digital transformation

Rule: always pair one of these with a sector term above. Never search them alone.
